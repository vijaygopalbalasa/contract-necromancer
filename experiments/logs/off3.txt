Things to know:
- **Contracts are not in `npm test`.** The script runs `test/*.test.js`, so `contracts/ledger/properties.contract.test.js` only runs if called directly with `node --test contracts/ledger/properties.contract.test.js`. I left `package.json` alone. Adding the path to the script is a one-line change if you want it included.
- **Replay seeds:** Case 0 of a run uses the seed itself. That is what makes a reported case seed replay as a one-run check.
- **Case-insensitive sort:** `splitExpense` sorts keys case-insensitively, as Req 2.1 says. Parsed keys are already lowercase, so the results match.
- **Unknown flags:** The CLI prints the usage sentence for any flag other than `--json`. The requirements do not cover this, so it is my choice.

Each file carries its own copy of the helpers and the fixtures it needs. Tests build a throwaway project in a temp directory. They call `bin/necro.js` the way Kiro does, so hooks get a JSON payload on stdin. A few call `src/canon.js` and `src/contracts.js` directly. Some tests need `git`, symbolic links and `/bin/sh`.

Each file also names the modules it uses in a `from '...'` comment. That makes a receipt pin `bin/necro.js` and the rest of `src/`, which an import alone would not.

How I checked them:
- I copied the repo to a temp folder and ran `necro freeze necro-core`, `check` and `verify` there. All 68 contracts pass, and the receipt confirms.
- Every task in `tasks.md` names criteria that have a contract.
- I applied about 70 deliberate bugs to a copy of `src/` and the templates. The contracts caught all of them except a few that turned out to be harmless changes. One of those showed that R6.5 needed a no-lock case, and I added it.

Four things to know before you freeze:
- **R4.8 (no contracts ran):** The code never says "no contracts ran". For a file with no tests it prints `Contracts failed: <file name>.`, so the contract checks exit 2, that the file is named, and that no receipt is written. The sentence exists only in `src/check.js`, where it can't be reached.
- **R4.4 (`node --test`):** The code runs files through the `run()` API rather than `node --test`. The contract checks that the Node test runner started each run, and that it ran once per tick.
- **Run time:** Through necro, each gate, `check` and `verify` takes about 30 seconds, because the files run one after another. `node --test` on the folder takes about 6 seconds. That fits the 300-second hook timeout.
- **Hook field name:** Only a field named `command` is exempt from the length check, and the shell-tool tests use that field. A long string in another field, such as `input` on `control_bash_process`, would be blocked.

The README lists the lock fields the tests read (`names`, `tasks[id].criteria`, `tasks[id].text`) and the partial-coverage notes. To freeze, run `necro freeze necro-core`.

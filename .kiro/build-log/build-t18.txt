**A sub-line counts only if it is just the reference.** The frozen `R2.7` contract has this sub-line: `Test first: a sub-bullet that names (Req 9.9) is not a task line.` It expects task 1 to record only `1.1, 1.2, 1.3`. Criterion 2.9 read literally would have recorded `9.9` and failed that frozen contract.

So a sub-line is read only when, after its list marker, it is nothing but `(Req ...)` or `_Requirements: ...__`. A sentence that mentions a criterion in passing is ignored, and Kiro's own format fits this rule. If you want any `(Req ...)` anywhere on a sub-line to count, `R2.7` would have to change first, and that is your call.

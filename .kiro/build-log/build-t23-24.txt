  - Blank lines are ignored.

  - Notifications get no reply.
  - An unknown protocol version gets the latest one the server supports.

  - `necro_status` takes an optional spec. It uses the gate's own `requiredNames`, so it reports what ticking each task would check. The last unticked task shows every contract.
